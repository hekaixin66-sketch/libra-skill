# 笔记生成

## 第一阶段：研究与5个标题

1. 整理用户给出的业务事实，读取 analysis.md 的“逆向拆解方法”。按本篇人群和触发场景判断需求入口、使用者与付费者，确定希望发生的一项行动。对本地服务/获客笔记，按本篇主要顾虑收集对应事实：服务区域与时段、故障或项目范围、收费及“不成交/不维修”规则、处理流程、售后条件、可公开的真实案例或凭据；不必每篇罗列全部信息。产品能力、价格、经历和结果以材料为准，缺项标待确认，不编造。信息不足仍可先给推演稿或带清晰占位的可填写稿，并列出发布前最需要补齐的事实。
2. 读取 [站内样本搜索](sample-search.md)，优先通过浏览器在小红书网页搜索并读取详情，不以MCP连接为前置条件。实际检索相似行业、同人群且需求相近的笔记，优先3–5篇可读样本。逐篇保存来源、可见信息、关键词、用户痛点、标题机制与可借鉴结构。仅凭高互动不能称爆文；有可比基准再称相对高表现样本，否则称参考笔记。
3. 结合已有材料和样本完成 analysis.md 的“简短策划记录”：选择主欲望与主阻力，比较用户原有预期、替代方案及真实交付，提取主关键词，并记录哪条事实能支撑点击后的信任判断。心理解释注明证据或假设；热点须核实语境与日期。需要启发时按阻力选读 marketing-cases.md 的案例，迁移决策机制，不能把品牌案例或本次推演写成自己的客户经历。
4. 按 analysis.md 的“同屏为什么先点我们”检查竞争卡片和缩略图，简要说明重复表达、可用差异与点击理由。输出恰好5个候选标题表：编号｜标题｜主关键词｜回应的欲望或阻力｜差异化点击理由。每个标题可配一句封面主信息草案，完整封面在确认后制作。围绕同一目标人群比较有依据的角度，不硬凑五种心理或强加热点；承诺必须可兑现。未能检索或观察同屏时明确为推演，不声称已验证CTR。
5. 等待用户选择编号、组合修改或授权自主选择，不擅自生成5篇完整笔记。已有明确标题或自主选择授权时直接复用，不重复索要确认。用户明确选择多篇时，逐篇执行第二阶段。

## 第二阶段：正文、封面、评分

读取 editorial-methods.md 的首行写作方法，内部比较开头后交付最佳稿；正文承接选定的主欲望或主阻力，兑现首行与标题的承诺。沿用目标人群的自然表达，不把内部心理分析写进成稿；没有真实经历时用明确标注的示例或直接介绍，不添加“最近帮几个老板”“发完就有人问”等故事来制造真人感。写本地维修、电路、设备等专业服务时，可把真实收费规则、到场范围、处理步骤或匿名化工单作为信任证据；没有具体证据就说明待补，不虚构数字或评价。提供DIY建议时只写普通用户可安全执行的基础检查；涉及带电电路、拆机或专业操作时，引导联系具备资质的人员，不写危险操作步骤。

围绕已确认标题的一个主关键词输出：
- 标题与主关键词。
- 封面主文案、副文案、布局、画面元素和视觉重点；主文案突出一个点击理由，标题补关键词或条件。按缩略图尺寸检查识别、文字对比与层级，并与可见竞争卡片比较。用户要大字报时保留直接性，不为装饰削弱信息。
- 完整正文：开头直接呈现选定的价值、机会或场景。教程提供与主题直接相关且安全的步骤/清单/判断方法；获客短文优先交代能解除主要顾虑的真实交付、费用、服务边界、证据和参与方式，不强行扩成教程或长篇痛点推销。缺少关键数字时标待补或改用已知规则，不为增加“信息量”虚构数值。结尾自然引导一个相关行动。篇幅服从用户要求与内容需要，不为凑字数重复。
- 3–6个相关话题建议，标明未核验平台话题页时只是建议；不搭无关热点。
- 封面图或可直接使用的生图提示词。根据用户偏好设定比例，未指定默认竖版3:4；明确文字、层级、色彩、主体、安全留白。当前环境有可用生图工具则读取对应技能直接生成；不能用代码占位图冒充AI生图。生成后检查实际文字与主题，无法可靠呈现中文时附独立准确文字稿，说明需排版校正。
- 使用 scoring.md 输出CQS逐项报告、总分和主要修改建议；用户选择简版时只显示最终分及必要限制。未实际生成或看到封面只能将视觉维度标 N/A，按已评权重给暂评，不能用默认分代填。图片数量、字数、数字密度和固定排版没有适用于所有笔记的统一门槛；只有与本篇阅读、证明、点击或用户指定要求有关时，才作为修改建议。

已明确的问题先修订再交付；评分针对最终版本。用户后续改主关键词时同步修改封面、标题、正文与话题。

交付前用策划记录回查：吸引来的人是否匹配业务，缩略图是否给出明确点击理由，正文是否提供解除主阻力的事实，用户是否清楚下一步付出与所得。缺少真实条件时说明缺项；如果瓶颈在业务交付，先提出可选的服务改进，不将未确认方案写成现有承诺。发布后按 analysis.md 的反馈方法和 scoring.md 的口径验证；CTR、咨询质量和CQS分别报告。

### 使用外部 CQS 报告

把外部报告当作待核对的评审意见，不直接照单全收：

1. 核对它评的是当前这篇稿、封面和行业，排除串入其他行业的建议、事实错误和文本中已存在的信息（例如误报“没有话题标签”）。复算单维加权和、缺项处理及四舍五入；若与报告总分不一致，同时注明原报分与复算结果，不猜测隐藏评分项或悄悄改分。
2. 把意见分为：稿件可直接修改、需要用户提供真实资料、需用当前官方来源核实、与本篇目标无关/缺乏依据。只执行有证据且符合目标的修改。
3. 价格、案例、工单、时间、覆盖区域、客户原话和返修率都只能来自用户材料或可核验来源；案例需有发布授权并去除个人信息。报告给出的“上周某小区”“XX元”示例是占位或编写建议，不是事实证据。
4. 数字是帮助比较或决策的一种信息形式，不是信息密度的硬指标。步骤、适用范围、明确规则和可信说明也能提供有效信息。不要为了凑数字、字数、图片数量或小标题而扩写。
5. 外部模型分数按其规则原样注明来源；需要本技能 CQS 时独立按 scoring.md 计算。缺少视觉素材按 N/A，不套用外部模型的占位分。平台规则、算法说法、固定字数/图片数/标题长度等动态或普适主张，先核查来源、日期和适用范围；无法核实时不要写成硬性规则。
