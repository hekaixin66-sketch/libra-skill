# 内容诊断报告模板

按资料充分程度删减，不填造数据。只看评分时用一行评分加必要限制替代报告。

## 核心结论

笔记目标、人群、主关键词；最主要的优势与瓶颈。CQS / CES / 综合分与完整或暂评状态。注明“CQS五维自测版v1.0；CES及综合分为内部模型，非平台官方评分”。

## 数据与证据

来源链接、采集日期、发布时间、统计截止时间、发布后时长、可见资料与缺失项。发布后附原始计数、分母、比率及同时间窗基准样本来源；不混淆曝光和阅读。

## 质量与效果

CQS表：维度｜权重｜0–100评分｜折算分｜证据｜修改动作。附覆盖率。
CES表（具备数据时）：指标｜原始计数/阅读｜比率｜基准数量｜百分位｜加权分。
综合结论：内容结构与实际反馈是否一致；区分观察事实、可能解释和待验证假设。

自动评分报告如同时提供，在独立小节记录来源模型及其分数，并简要指出已采纳、待补真实资料、需核实和不相关/错误的建议。不得把外部模型分数混入本 CQS。缺少封面时视觉 N/A，按内部评分规则计算暂评；不要为满足报告建议而虚构案例、价格、配图或固定字数。

## 内容拆解

按 analysis.md 的决策链记录：触发场景与需求入口；主欲望、主阻力及其证据/假设；真实价值和信任依据；同屏点击理由；中文语境与关键词；正文兑现及下一步行动。最多提炼3个实际吸引词，不硬凑痛点或冲突。

有后台数据时，将曝光、同口径CTR、有效咨询及后续转化分别列出，指出目前能定位和仍未知的环节。没有数据只作内容诊断，不能把未点击、点击后未咨询、零曝光都归为同一种失败，也不能只因浏览少判定账号受限。

## 流量阶段估计

阶段或待判断｜证据｜其他可能解释｜置信度｜缺失数据。明确不是平台官方流量池判定；不硬设“500/5000”等通用门槛。

## 改进优先级

最多3项主要动作，每项列问题、具体改法、预期改善的指标与验证方式。优先改影响最大的环节；对比实验尽量只变一个因素，记录调整时间并使用可比观察窗，不把同期自然波动归功于修改。
