# Libra skill

Libra 的小红书内容运营 Skill，帮助从用户需求、心理预期和同屏竞争出发，策划、生成、拆解与复盘小红书笔记。

## 包含内容

- 逆向拆解需求、欲望、阻力、信任依据和行动路径
- 搜索型与内容激发型需求分流，关键词和热点核验
- 同屏竞争下的封面与标题点击理由
- 营销案例参考及迁移边界
- CQS 内容自检、CES 发布后反馈分析
- 外部自动评分报告的核验方法，避免照单全收或编造案例、价格和效果

## 安装

将本仓库内容复制到 Codex Skills 目录下的 `xiaohongshu-content` 文件夹：

- Windows：`%USERPROFILE%\.codex\skills\xiaohongshu-content`
- macOS / Linux：`~/.codex/skills/xiaohongshu-content`

之后可在 Codex 中调用 `xiaohongshu-content` Skill。更新文件后重新打开对话或重新加载技能。

## 说明

CQS 使用本项目 `references/scoring.md` 中注明的第三方自测模型，不是小红书官方指标或流量保证。涉及实时热点、平台规则或具体服务事实时，按 Skill 中的来源与证据要求核验。
